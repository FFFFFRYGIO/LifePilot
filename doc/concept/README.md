# LifePilot concept

Early design material for LifePilot: product scope, architecture sketch, category behaviour, and static UI mockups. Nothing here is production code; it guides what to build and how screens might work.

## Contents

| Document / folder | Purpose |
|-------------------|---------|
| [planned-features.md](planned-features.md) | Planned feature areas (shopping, pantry, chores, tasks, calendar, health, hobbies, goals, automation) |
| [solution-structure.md](solution-structure.md) | High-level client–API–database layout |
| [categories.md](categories.md) | Per–life-area panels, tile colours, and status rules for the category grid |
| [ui-prototype.md](ui-prototype.md) | How to open and navigate the static HTML prototype |
| [ui-prototype/](ui-prototype/) | Mobile-first HTML/CSS mockups (open [index.html](ui-prototype/index.html) in a browser) |
| [diagrams/](diagrams/) | Concept and solution-structure diagrams (`.mmd` sources and `.png` exports) |
| [notes/](notes/) | Working notes and prompts (e.g. backlog, category doc updates) |

Start with [planned-features.md](planned-features.md) for the product map, or [ui-prototype/index.html](ui-prototype/index.html) to click through screens.
